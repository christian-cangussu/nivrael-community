# Nivrael: Path of Immortals

Landing page for **Nivrael**, a Xianxia cultivation idle RPG on Telegram.

## Tech Stack
- React 18 + TypeScript + Vite
- Tailwind CSS
- Deployed via Docker + Nginx

## Development
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```
